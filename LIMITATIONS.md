# Limitations

- Prototype only; not production software.
- The local dataset is small and observational.
- The demo fixture and specialist text are deterministic; it demonstrates software mechanics rather than real model-generated scientific reasoning.
- The demo is not scientifically meaningful evidence for the underlying relationship; it is a process-integrity demonstration.
- Specialist output is candidate reasoning, not fact.
- No causal inference claim is made.
- v0 memory retrieval is deterministic tags/criteria only; no embeddings.
- No proprietary feature-discovery integration exists.
- No deployment, trading, external execution, or autonomous truth authority exists.
- The project makes no claim about dotData internal architecture.
